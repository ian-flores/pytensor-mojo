# Supported distributions and ops

The tables on this page are generated by `docs/gen/build_assets.py`. The distribution table
comes from the Phase 4 census, which runs `missing_ops` on each model's optimized logp +
gradient graph. The op tables come from the code generator's dispatch and scalar-op table.
`tests/test_docs_generated.py` fails if these tables differ from the code.

## Distributions

Every row below is also verified numerically: logp and gradient match PyMC at rtol 1e-10 on
24 points (`tests/test_phase4_models.py`). Likelihood rows use free parameters under simple
priors; prior rows use constant parameters and the default transform.

--8<-- "distributions.md"

Beyond single distributions, five complete models are sampled and checked against nutpie
([Benchmarks](../benchmarks.md)): a hierarchical linear regression, a Poisson GLM, a robust
StudentT regression, a hierarchical Beta-Binomial, and eight schools.

Not supported yet:

- **Missing ops:** incomplete gamma or beta (so CDFs, and censored or truncated likelihoods),
  trigamma, Bessel functions, linear algebra (MvNormal, LKJ), and anything built on `Scan`.
- **Untested:** mixtures, zero-inflated likelihoods, and the simplex transform (Dirichlet).
